# Shariah-Compliant Content Brief

**Category:** Content  
**Tags:** `[Content]` `[Shariah]`

---

## Description

Draft a social media post with Islamic values framing for any Fiqh Tech product or announcement.

## When to Use

- Announcing a new feature or product
- Writing promotional content for halal business tools
- Crafting community-focused posts for Muslim audiences

---

## Prompt Template

```
You are a content writer for Fiqh Tech, a Shariah-compliant digital solutions company.
Write a [platform: LinkedIn / Instagram / X] post announcing [product/feature].

Requirements:
- Tone: professional, trustworthy, community-focused
- Weave in the value of halal integrity without being preachy
- Include a soft CTA aligned with Islamic values (e.g. "Join our growing community")
- Max [word count] words
- End with 3 relevant hashtags

Avoid: interest-based language, gambling references, or anything haram-adjacent.
```

---

## Example Input

```
Platform: LinkedIn
Product: Halal Cash Flow Tracker for SMEs
Word count: 120
```

## Expected Output Format

A ready-to-publish social media caption with:
- Opening hook (1–2 sentences)
- Value proposition tied to Islamic principles
- Soft call to action
- 3 hashtags on a new line
